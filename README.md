# Block Book

A ground-floor storefront case file for San Francisco. Built for the Abundance SF civic buildathon — **What Retail Could Thrive Here**.

The map exists. The listing exists. The vacancy tax exists. The file does not. Block Book is that file.

## Run

```bash
npm install
npm start
```

- App: http://localhost:3000/blockbook.html
- Slides: http://localhost:3000/blockbook-slides.html

## Demo

Downtown → coffee shop → **901 Market** (too big, live city records) → **101 Spear** (former café).

## What it is

One file per storefront:

- A graded vacancy claim — verified, likely, possible, marketed, occupied, or unknown
- Live SF Open Data — Treasurer registered businesses and DBI building permits, queried to this address
- A street read — spend, hours, last tenant, what this sidewalk will actually support
- Official grant, OSB, Recorder, and Permit Center links already pointed at this lot

Interior condition stays unknown until a human walks it. California law: the Assessor does not post the owner name online. The file gives the free path — OSB and the deed — not a guessed phone number.

Pilot, not a census.
